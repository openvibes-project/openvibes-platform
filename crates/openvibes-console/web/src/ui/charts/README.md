Small charts shared by pages. The alarm page (`views/investigate/alarm/`) is the first user.

| File | What it does |
|---|---|
| `HourlyBars.tsx` | 24 hourly bars as an SVG (hidden from screen readers) with a title per bar, and a hidden table of the values. |
