# panels/alarms

The panel for one threat alarm.

| File | What it does |
|---|---|
| `AlarmPanel.tsx` | The alarm in the shared triage detail template: process, state, assignee, case, suppressions. |
| `DetectionEvidence.tsx` | The evidence section: how the alarm was detected and its ATT&CK pairs. |
