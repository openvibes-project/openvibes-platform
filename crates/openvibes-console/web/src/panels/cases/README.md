# panels/cases

Cases in the inspector, and the control that puts items into them.

| File | What it does |
|---|---|
| `CasePanel.tsx` | One case: status, items, notes and timeline, and closing it. |
| `AddToCase.tsx` | The "Add to case" button on alarms, findings, vulnerabilities, hosts and software. |
| `CaseBadge.tsx` | Marks list rows that are in an open case. |
| `cases.ts` | Case logic without React: item kinds, list query, closing rules, request bodies. |
