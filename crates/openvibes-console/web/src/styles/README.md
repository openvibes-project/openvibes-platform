# styles

The console's CSS, loaded in this order by main.tsx.

| File | What it does |
|---|---|
| `tokens.css` | Design tokens: colours, spacing, type, light and dark. |
| `base.css` | Base element rules and resets. |
| `components.css` | Buttons, badges, inputs, tables and other shared components. |
| `shell.css` | The app frame and rail. |
| `panels.css` | The inspector, panel content and tile rows. |
